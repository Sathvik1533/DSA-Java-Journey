# Arrays — Searching

## Concept

Locating a value or position that satisfies a condition.

## Pattern

Choose linear scanning for unsorted data; use ordered-data techniques only when their preconditions hold.

## Recognition Keywords

Find, contains, target, position, first occurrence, last occurrence.

## Story

Look through labeled lockers until the target is found.

## Common Mistakes

- Returning the wrong sentinel when absent
- Assuming data is sorted
- Mishandling duplicate values

## Time Complexity

Linear search: `O(n)`.

## Space Complexity

`O(1)` auxiliary space.

## Future Connections

Sorted arrays, binary search, hash-based lookup.
