# Graphs

## Concept

Represent entities and relationships as vertices and edges.

## Pattern

Choose a representation and traversal that matches direction, weights, and connectivity requirements.

## Recognition Keywords

Node, edge, path, connected, cycle, directed, weighted.

## Story

Cities connected by roads, with each question asking about a different kind of route.

## Common Mistakes

- Forgetting visited-state management
- Treating directed edges as undirected
- Choosing the wrong representation

## Time Complexity

Record using vertices `V` and edges `E`.

## Space Complexity

Include graph representation and traversal state.

## Future Connections

BFS, DFS, shortest path, topological sorting, union-find.
