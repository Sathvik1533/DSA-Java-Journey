# Trees

## Concept

Hierarchical data organized by parent-child relationships.

## Pattern

Use traversal and recursive or iterative state appropriate to the question.

## Recognition Keywords

Root, child, subtree, depth, height, traversal, ancestor.

## Story

A family hierarchy where each person may lead smaller branches.

## Common Mistakes

- Missing base cases
- Mixing node depth and tree height
- Not restoring recursive state when required

## Time Complexity

Record per traversal or operation.

## Space Complexity

Include recursion stack or explicit traversal storage.

## Future Connections

BST, heaps, graphs, dynamic programming on trees.
