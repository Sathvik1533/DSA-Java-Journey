# Pattern Dependency Map

DSA is a dependency graph: learn prerequisite patterns before relying on their advanced forms.

```text
Traversal
    ↓
Accumulation
    ↓
Running Sum
    ↓
Prefix Sum
    ↓
Sliding Window

Traversal
    ↓
Comparison
    ↓
Maximum / Minimum
    ↓
Kadane’s Algorithm

Linear Search
    ↓
Sorted Arrays
    ↓
Binary Search

Traversal
    ↓
Frequency Counting
    ↓
Hashing
    ↓
Hash-based Window State
    ↓
Variable Sliding Window

Arrays
    ↓
Two Pointers
    ↓
Partitioning / Palindrome / Pair Problems

Recursion
    ↓
Tree Traversals
    ↓
BST Operations / Tree DP

Graph Representation
    ↓
BFS / DFS
    ↓
Connected Components / Shortest Paths / Topological Sort
```

## Maintenance rule

When a new pattern is learned, add its prerequisite edge and the advanced patterns it unlocks.
