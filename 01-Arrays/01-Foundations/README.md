# Arrays — Foundations

## Concept

Array declaration, indexing, length, and direct access.

## Pattern

Use index-based access safely within valid bounds.

## Recognition Keywords

Index, length, first element, last element, access.

## Story

Numbered lockers: each value lives at a known position.

## Common Mistakes

- Accessing outside `0` to `length - 1`
- Forgetting zero-based indexing

## Time Complexity

Direct access: `O(1)`.

## Space Complexity

No additional space for direct access: `O(1)`.

## Future Connections

Traversal, searching, two pointers.
