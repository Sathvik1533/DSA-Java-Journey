# Accumulation Pattern

## Recognition Keywords

- Sum
- Total
- Average
- Count
- Product

## Goal

Continuously update one variable while traversing the array.

## Golden Rules

- Initialize correctly.
- Update every iteration.
- Print after traversal.

## Identity Element

Addition → 0

## Complexity

Time : O(n)

Space : O(1)
