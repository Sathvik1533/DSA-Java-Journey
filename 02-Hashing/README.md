# Hashing

## Concept

Store and retrieve values by keys for efficient membership and frequency tracking.

## Pattern

Choose a map or set based on whether associated counts/values are needed.

## Recognition Keywords

Frequency, duplicate, lookup, pair, complement, distinct.

## Story

Use labeled drawers to find or update information by name.

## Common Mistakes

- Using a set when counts are needed
- Incorrect key/value update order
- Forgetting expected versus worst-case behavior

## Time Complexity

Typical lookup/update: `O(1)` average.

## Space Complexity

Depends on number of distinct keys.

## Future Connections

Frequency arrays, two sum patterns, sliding window.
