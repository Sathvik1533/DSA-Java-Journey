# Traversal Pattern

## Recognition Keywords

- Print
- Visit
- Traverse
- Iterate
- Process every element

---

## Goal

Visit every valid element exactly once.

---

## Golden Rules

- Number of iterations = arr.length
- Last valid index = arr.length - 1
- Empty array → 0 iterations
- Visit every valid index exactly once

---

## Complexity

Time : O(n)

Space : O(1)
