# Arrays — Comparison

## Concept

Comparing values to select, rank, or validate them.

## Pattern

Maintain the best candidate or compare adjacent/relevant values under a rule.

## Recognition Keywords

Maximum, minimum, largest, smallest, greater than, equal.

## Story

Judge each contestant against the current leader.

## Common Mistakes

- Incorrect initial candidate
- Missing ties
- Updating the candidate too early

## Time Complexity

Typical full pass: `O(n)`.

## Space Complexity

Typical candidate tracking: `O(1)`.

## Future Connections

Maximum/minimum, Kadane’s algorithm, binary search preconditions.
