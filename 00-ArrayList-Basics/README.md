# 00-ArrayList-Basics Reference Guide

An understandable index system that breaks down basic Java list tools into simple, everyday patterns for memory and storage tracking.

## 📁 Simple File Descriptions

* **01_AddAndPrintNumbers**: Storing elements and using loops to display lists.
* **02_ChangeValueAtIndex**: Modifying individual data blocks at a single location.
* **03_CheckSizeGrowth**: Monitoring lists to watch item counts expand.
* **04_DeleteLastItem**: Dropping tail items to manage step-by-step path resets.
* **05_DeleteByPosition**: Removing items using location indexes, forcing left-shifts.
* **06_DeleteByActualValue**: Deleting a piece of data by matching its literal content.
* **07_CheckIfListIsEmpty**: Instant questions verifying if data has been entered.
* **08_WipeListCompletely**: Dumping out all values to clean out code state tracks.
* **09_ModernListCreation**: Comparing modern declaration formats against old structures.
* **10_FixedListCrashTrap**: Highlighting errors caused by trying to edit locked lists.
* **11_ConvertFixedToFlexible**: Upgrading locked lists into adjustable structures.
* **12_SortSmallestToLargest**: Arranging values sequentially from low to high thresholds.
* **13_SortLargestToSmallest**: Reversing lists to grab high priority elements first.
* **14_CombineTwoLists**: Merging full data sets together in block transfers.
* **15_RemoveDuplicatesAndSort**: Multi-step filtering that leaves only ordered, unique data.
