# Pattern Book

## Traversal

- **Recognition Keywords:** visit every element, scan, print, iterate
- **Story:** walk through a sequence one position at a time
- **Mini Version:** one forward pass
- **Advanced Version:** traversal combined with state tracking
- **Future Uses:** accumulation, comparison, frequency, two pointers

## Accumulation

- **Recognition Keywords:** sum, count, total, aggregate
- **Story:** maintain a growing total while reading values
- **Mini Version:** one scalar accumulator
- **Advanced Version:** running sums and prefix structures
- **Future Uses:** prefix sum, sliding window, dynamic programming

## Comparison

- **Recognition Keywords:** maximum, minimum, best, largest, smallest
- **Story:** compare each candidate against the current leader
- **Mini Version:** track one best value
- **Advanced Version:** optimal subarray and feasibility decisions
- **Future Uses:** Kadane’s algorithm, binary search predicates
